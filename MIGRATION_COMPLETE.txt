✅ APPWRITE SETUP CHECKLIST
============================

1. ☐ Create Appwrite account at https://cloud.appwrite.io
2. ☐ Create new project
3. ☐ Create "images" bucket (max 5MB)
4. ☐ Create "videos" bucket (max 50MB)
5. ☐ Set permissions on both: public read, authenticated write
6. ☐ Create API key with "files.read" and "files.write" scopes
7. ☐ Copy Project ID to VITE_APPWRITE_PROJECT_ID
8. ☐ Copy API Key to VITE_APPWRITE_API_KEY
9. ☐ Add to .env.local

See SETUP_APPWRITE_ONLY.txt for step-by-step instructions

✅ DATA FLOW
===========

Text Post:
  User input → Firebase Firestore → Real-time listener → Display

Image Upload:
  Select image → Validate → Upload to Appwrite (images bucket) → Get file ID → 
  Save file ID to Firestore → Real-time listener → Display via getAppwriteMediaUrl()

Video Upload:
  Select video → Validate → Upload to Appwrite (videos bucket) → Get file ID → 
  Save file ID to Firestore → Real-time listener → Display via getAppwriteMediaUrl()

Like/Comment:
  User action → Firebase Firestore → Real-time listener → Update UI


✅ STORAGE PATHS
=================

Firebase Firestore Collections:
  /posts (text, imageUrl/videoUrl file IDs, metadata)
  /comments (text, user, post reference)
  /likes (post reference, user)
  /users (username, user ID)
  /reports (reason, post reference)

Appwrite Storage:
  /images (bucket) → file ID: {file_id}
  /videos (bucket) → file ID: {file_id}

Access URLs:
  Images: getAppwriteMediaUrl(fileId, 'image')
  Videos: getAppwriteMediaUrl(fileId, 'video')
