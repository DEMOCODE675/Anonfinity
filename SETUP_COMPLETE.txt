NEXT STEPS - DO THIS NOW
========================

STEP 1: SET UP FIREBASE FOR IMAGES
===================================

1. Go to: https://console.firebase.google.com
2. Create new project (or use existing)
3. Go to: Storage → Security Rules
4. Replace rules with content from FIREBASE_STORAGE_RULES.txt
5. Click "Publish"
6. Go to: Project Settings → General
7. Copy these values:
   - API Key
   - Project ID
   - Auth Domain
   - Storage Bucket
   - Messaging Sender ID
   - App ID

8. Add to .env.local:
   VITE_FIREBASE_API_KEY=your_value_here
   VITE_FIREBASE_PROJECT_ID=your_value_here
   VITE_FIREBASE_AUTH_DOMAIN=your_value_here
   VITE_FIREBASE_STORAGE_BUCKET=your_value_here
   VITE_FIREBASE_MESSAGING_SENDER_ID=your_value_here
   VITE_FIREBASE_APP_ID=your_value_here

STEP 2: SET UP APPWRITE FOR VIDEOS
===================================

1. Go to: https://cloud.appwrite.io
2. Create account (free tier)
3. Create new project
4. Go to: Storage
5. Create new bucket:
   - Name: videos
   - ID: videos
   - Max size: 52428800 (50MB)
   - Allowed files: mp4 webm gif
6. Go to: Settings → API Keys
7. Create API Key named "Web App Videos"
   - Check: files.read
   - Check: files.write
   - Copy the key
8. Go to: Settings → General
9. Copy: Project ID

10. Add to .env.local:
    VITE_APPWRITE_ENDPOINT=https://cloud.appwrite.io/v1
    VITE_APPWRITE_PROJECT_ID=your_project_id
    VITE_APPWRITE_API_KEY=your_api_key
    VITE_APPWRITE_VIDEOS_BUCKET=videos

TROUBLESHOOTING
===============

Problem: "Image upload fails"
Solution:
- Check Firebase rules are published
- Check .env.local has all Firebase values
- Verify image is JPEG/PNG/GIF/WebP < 5MB
- Restart dev server

Problem: "Video upload fails"
Solution:
- Check .env.local has all Appwrite values
- Verify video is MP4/WebM < 50MB
- Check Appwrite console for bucket creation
- Restart dev server

Problem: "Videos don't play after upload"
Solution:
- Check Appwrite bucket permissions
- Verify video file is valid MP4/WebM
- Check browser console for errors
- Try refreshing page

Problem: "getAppwriteVideoUrl is not a function"
Solution:
- Ensure imageUpload.js was updated with Appwrite code
- Restart dev server
- Clear node_modules cache: npm cache clean --force

FILE LOCATIONS
===============

Firebase Images:
- Stored at: /posts/images/{filename}
- Max size: 5MB
- Formats: JPEG, PNG, GIF, WebP
- Access: Public (via downloadUrl)

Appwrite Videos:
- Stored in bucket: videos
- Max size: 50MB
- Formats: MP4, WebM, GIF
- Access: Public (via getAppwriteVideoUrl)

PRODUCTION DEPLOYMENT
======================

When ready for production:

1. Firebase:
   - Create production project
   - Update Firebase rules for production domain
   - Add production domain to CORS rules
   - Use production API key in .env.local

2. Appwrite:
   - Deploy Appwrite to production server (or use cloud)
   - Create production bucket
   - Create production API key
   - Update VITE_APPWRITE_ENDPOINT to production URL
   - Set bucket permissions for production domain

3. Environment:
   - Create separate .env.production file
   - Never commit API keys to Git
   - Use GitHub Secrets for CI/CD
   - Test all uploads on production before launch
